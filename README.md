# Full Library Management System

A Flask based library management system with MySQL database.

## Features
- Admin login
- Member management
- Book issue & return
- Browse books
- Overdue tracking

## Technologies
- Python
- Flask
- MySQL
- HTML
- CSS

## Setup Instructions

1 Install XAMPP  
2 Start Apache and MySQL  

3 Create database in phpMyAdmin

library_system

4 Import

database/the_reading_hub (1).sql

5 Install dependencies

pip install -r requirements.txt

6 Run project

python app.py

Open browser:

http://127.0.0.1:5000
